# الأمن، الخصوصية، والحدود القانونية

## قواعد غير قابلة للتجاوز

- لا تعريض عام من هذا الكمبيوتر.
- لا تشغيل على نفس VLAN التي تحتوي أجهزة أو حسابات حقيقية.
- لا اتصال صادر من منطقة الخداع، ولا DNS عام لها.
- لا تنفيذ أوامر أو سكربتات أو استعلامات خام يرسلها طرف غير موثوق.
- لا رفع عينات malware حقيقية في بيئة Windows المحلية؛ استخدم EICAR داخل مختبر مخصص فقط.
- لا تخزين كلمات مرور مهاجم خام في واجهة أو log؛ تُحفظ قيم مموّهة/hashed حسب السياسة.
- أي نص أمر أو script في SOC يُعرض escaped/defanged.

## النشر الحقيقي

يتطلب host منفصلًا أو Linux VM، VLAN مخصصة، firewall deny-by-default، egress proxy مغلق، VPN للوصول الإداري، TLS، OIDC/MFA، نسخ احتياطي مشفّر، ومراقبة الموارد. يجب اختبار منع الخروج فعليًا قبل فتح أي inbound rule.

## سياسة احتفاظ مقترحة

| النوع | الاحتفاظ | السبب |
|---|---:|---|
| أحداث منقحة | 90 يومًا | التحليل والاتجاهات |
| Raw logs | 30 يومًا | التحقيق قصير المدى |
| PCAP | 7–14 يومًا | عالي الحساسية والحجم |
| ملفات مرفوعة | 7 أيام quarantine | تقليل المخاطر |
| IOC عالي الثقة | 180 يومًا | المقارنة التاريخية |
| بيانات واجهة demo | قابلة لإعادة التوليد | صناعية بالكامل |

تُراجع السياسة قانونيًا قبل جمع IP عام. يلزم توثيق الغرض، تقليل البيانات، التحكم في الوصول، آلية حذف، سجل تدقيق، وإشعار داخلي واضح. لا تُرسل ملفات أو IP إلى VirusTotal أو أي طرف خارجي دون موافقة وسياسة مشاركة بيانات.

## الاستجابة للحوادث

عند الاشتباه بخروج غير متوقع: افصل شبكة sensor، التقط حالة الحاويات والـlogs، لا تشغّل الملف المرفوع، دوّر الأسرار التشغيلية، راجع firewall وDNS، واحفظ الأدلة بسلسلة custody موثقة.
