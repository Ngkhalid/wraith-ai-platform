# مراجعة المراجع مفتوحة المصدر

## OWASP Honeypot-Project

مرجع بحثي مفيد لتوحيد event schema والتكامل مع Elastic/MISP. المشروع ما زال أقرب إلى PoC، ولم نعتمد نسخ كوده داخل هذا المشروع. قبل إعادة استخدام أي جزء يجب التحقق من الترخيص الفعلي للملف المقصود.

## awesome-honeypots

قائمة تصنيف ومقارنة وليست مكوّن تشغيل. استُخدمت لاختيار فئات مناسبة: Cowrie لمحاكاة SSH/Telnet، OpenCanary للخدمات منخفضة التفاعل، وSuricata للرؤية الشبكية.

## ThalesGroup/dd-honeypot

ترخيص Apache-2.0 وبنية JSONL/fake filesystem مفيدان كمرجع. لم يُشغّل أو يُنسخ كما هو، لأن التصميم الأصلي يسمح بمسارات خطرة للاستخدام المباشر: جلب URL يحدده المهاجم، كتابة ملفات، تسجيل كلمات مرور خام، رفع SCP بلا quotas واضحة، اعتماد AWS Bedrock، وحاوية بصلاحيات غير مناسبة للمختبر المحلي. أُعيد تصميم المسار هنا بحيث لا يوجد download أو host write أو تنفيذ.

## قرار الاعتماد

- **Cowrie/OpenCanary/Suricata**: تكامل اختياري في Linux sensor zone بعد العزل.
- **OWASP/dd-honeypot**: مراجع تصميم فقط.
- لا توجد أسرار أو بيانات أو أسماء شركات مأخوذة من هذه المستودعات.
